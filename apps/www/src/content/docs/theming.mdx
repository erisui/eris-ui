`init` puts the theme in `src/styles/eris-theme.css`. It defines the tokens as CSS variables and maps them to Tailwind utilities like `bg-surface` and `rounded-card`. Change a variable and every component follows.

<CodeBlock
  lang="css"
  title="src/styles/eris-theme.css"
  code={`:root {
  --eris-background: #141414;
  --eris-surface: #191919;
  --eris-foreground: #f5f5f5;
  --eris-radius-card: 24px;
  /* ... */
}`}
/>

## Colour

| Token               | Default   | Used for                             |
| ------------------- | --------- | ------------------------------------ |
| `--eris-background` | `#141414` | Page                                 |
| `--eris-surface`    | `#191919` | Cards, dialogs                       |
| `--eris-field`      | `#1C1C1C` | Inputs                               |
| `--eris-raised`     | `#1F1F1F` | Secondary buttons, the tab indicator |
| `--eris-border`     | `#2A2A2A` | Borders                              |
| `--eris-foreground` | `#F5F5F5` | Text, the primary button             |
| `--eris-muted`      | `#8C8C8C` | Descriptions, helper text            |
| `--eris-danger`     | `#E07A90` | Destructive actions, errors          |
| `--eris-ring`       | `#628AF7` | Focus rings                          |

The accent button uses its own gradient tokens (`--eris-accent-top`, `--eris-accent-bottom`, `--eris-accent-highlight`, `--eris-accent-border`). Use it for the single most important action on a screen.

Every filled button shares one lighting model: a border, a 1px highlight on the top edge and the same drop shadow. The primary button takes `--eris-primary-border`, `--eris-primary-highlight` and `--eris-primary-hover`; secondary and danger take `--eris-raised-highlight` and `--eris-raised-hover`; all of them share `--eris-button-shadow`.

## Light theme

The theme is dark by default. Add `data-theme="light"` to `<html>` for a light page, or to any element to make just that part light.

<CodeBlock code={`<html lang="en" data-theme="light">`} />

The primary button follows `--eris-foreground`, so it turns near-black on a light page. Danger, ghost and code colours get darker values to keep their contrast on white.

A few tokens exist so that parts can differ between the themes:

| Token                                | Used for                                     |
| ------------------------------------ | -------------------------------------------- |
| `--eris-track`                       | The tabs list and a switch that is off       |
| `--eris-switch-thumb`                | The thumb of a switch that is off            |
| `--eris-highlight`                   | The highlighted item in a menu or select     |
| `--eris-scrim`                       | The backdrop behind a dialog                 |
| `--eris-overlay-shadow`              | The shadow under dialogs, popovers and menus |
| `--eris-tooltip`, `--eris-tooltip-*` | The tooltip, which turns near-black on light |

To add your own colour, give it a value in both `:root` and `[data-theme="light"]`.

## Radius and the Eris curve

| Token                 | Default  | Used for              |
| --------------------- | -------- | --------------------- |
| `--eris-radius-pill`  | `9999px` | Buttons, tabs, badges |
| `--eris-radius-field` | `12px`   | Inputs                |
| `--eris-radius-menu`  | `16px`   | Menus, popovers       |
| `--eris-radius-card`  | `24px`   | Cards, dialogs        |

Elements with the `eris-curve` class get superellipse corners instead of circular ones, through `corner-shape: superellipse(1.25)`. The curve eases into the straight edge instead of meeting it at a seam. Browsers without `corner-shape` support show the normal radius, so nothing breaks. Remove the class to opt out.

## Motion

State changes take `--eris-duration-state` (150ms) and opening or closing takes `--eris-duration-open` (200ms), both on `--eris-ease`.

## Font

The theme asks for Geist through `--eris-font-sans`. Point it at another family to change the type everywhere.
