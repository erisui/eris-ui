## Open on load

Add `open` to an `AccordionItem` to show it when the page loads. The panel is in the HTML already, so it does not flash closed before the script runs.

## Several open at once

By default, opening an item closes the one that was open. With `multiple`, each item opens and closes on its own.

<Demo id="accordion-multiple" source={multipleSrc}>
  <Multiple />
</Demo>

## Always one open

Clicking the open item closes it. Set `collapsible={false}` to keep one item open at all times. This has no effect with `multiple`.

```astro
<Accordion collapsible={false}>
  <AccordionItem value="monthly" open>
    ...
  </AccordionItem>
</Accordion>
```

## Disabled items

A disabled item cannot be opened, and the arrow keys skip it. Put `disabled` on the `Accordion` to disable every item.

<Demo id="accordion-disabled" source={disabledSrc}>

</Demo>

## Heading level

Each trigger is a button inside a heading, so screen reader users can jump between sections. The heading is an `h3` by default. Set `as` to the level that fits your page outline.

```astro
<AccordionTrigger as="h2">Shipping</AccordionTrigger>
```

## Keyboard

| Key                                  | Does                                           |
| ------------------------------------ | ---------------------------------------------- |
| <kbd>Tab</kbd>                       | Moves focus to the next header or into a panel |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Opens or closes the focused item               |
| <kbd>↓</kbd> / <kbd>↑</kbd>          | Next or previous header, wrapping at the ends  |
| <kbd>Home</kbd> / <kbd>End</kbd>     | First or last header                           |

## Parts

| Component          | Renders                                                                 |
| ------------------ | ----------------------------------------------------------------------- |
| `Accordion`        | The root. Props: `id`, `multiple`, `collapsible`, `disabled`            |
| `AccordionItem`    | One section. Props: `value`, `open`, `disabled`                         |
| `AccordionTrigger` | The heading and button that toggle the item, with a chevron. Prop: `as` |
| `AccordionContent` | The panel shown when the item is open                                   |
