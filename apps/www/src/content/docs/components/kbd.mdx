## Shortcuts

Wrap keys pressed together in `KbdGroup`. When a shortcut reaches the end of a line, its keys move to the next line together instead of splitting. They only wrap when the shortcut is wider than the space it has.

</Demo>

## Symbols

Screen readers read some symbols by their Unicode name or skip them, so <kbd>↵</kbd> can come out as "downwards arrow with corner leftwards". Pass `label` with the key's name and screen readers say that instead. The symbol still shows on screen.

<Demo id="kbd-symbols" source={symbolsSrc}>
  <Symbols />
</Demo>

## Sizes

`md` is the default and fits body text and tables. Use `sm` in tighter spots, such as menus and search hints.

<Demo id="kbd-sizes" source={sizesSrc}>
  <Sizes />
</Demo>

## Parts

| Component  | Renders                              |
| ---------- | ------------------------------------ |
| `Kbd`      | One key. Props: `size`, `label`      |
| `KbdGroup` | Keys pressed together, such as ⌘ K   |

## Props

| Prop    | Type           | Default                           |
| ------- | -------------- | --------------------------------- |
| `size`  | `"sm" \| "md"` | `"md"`                            |
| `label` | `string`       | none; screen readers read the key |

Other attributes on `Kbd` and `KbdGroup` go straight to the `<kbd>` element.
