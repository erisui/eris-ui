## Items

A `MenuItem` is an action. Give it an `href` and it becomes a link that works with a click, with <kbd>Enter</kbd>, and with a middle click to open in a new tab. `variant="danger"` marks destructive actions, and `disabled` items are skipped by the arrow keys.

## Reacting to a choice

Choosing an item fires an `eris:select` event on it. The event bubbles, so one listener on the menu covers every item. `event.detail.value` is the item's `value`.

## Checkbox and radio items

A `MenuCheckboxItem` toggles on and off. `MenuRadioItem`s inside a `MenuRadioGroup` let the user pick one; set the group's `value` to the item chosen on load.

Their `eris:select` event also carries `checked`, and for a radio item `group`, the `name` of its group.

By default the menu closes after any choice. Here `closeOnSelect={false}` keeps it open so several options can be changed. You can also set `closeOnSelect` on a single item.

## Groups and separators

`MenuGroup` and `MenuRadioGroup` take a `label`, shown above their items and read out as the group's name. `MenuSeparator` draws a line between sections.

## Icon trigger

A trigger that shows only an icon needs an `aria-label`. A [Tooltip](/docs/components/tooltip) can wrap the trigger to show the same hint to everyone else.

## Placement

`placement` and `gutter` work as on [Popover](/docs/components/popover#placement). The default is `bottom-start`, 6 pixels from the trigger. A menu taller than the space available scrolls.

## Keyboard

| Key                                                           | Does                                                  |
| ------------------------------------------------------------- | ----------------------------------------------------- |
| <kbd>Enter</kbd>, <kbd>Space</kbd> or <kbd>↓</kbd> on trigger | Opens the menu on its first item                      |
| <kbd>↑</kbd> on the trigger                                   | Opens the menu on its last item                       |
| <kbd>↓</kbd> / <kbd>↑</kbd>                                   | Next or previous item. Wraps around with `loopFocus`  |
| <kbd>Home</kbd> / <kbd>End</kbd>                              | First or last item                                    |
| Letters                                                       | Jumps to the next item that starts with what you type |
| <kbd>Enter</kbd> or <kbd>Space</kbd>                          | Chooses the item                                      |
| <kbd>Esc</kbd>                                                | Closes the menu and returns focus to the trigger      |

<kbd>Tab</kbd> does not leave an open menu. Submenus and right-click context menus are not part of this
component yet.

## Parts

| Component          | Renders                                                                           |
| ------------------ | --------------------------------------------------------------------------------- |
| `Menu`             | The root. Props: `id`, `placement`, `gutter`, `closeOnSelect`, `loopFocus`        |
| `MenuTrigger`      | The button that opens it. Props: `variant`, `size`, `aria-label`                  |
| `MenuContent`      | The floating list                                                                 |
| `MenuItem`         | An action or link. Props: `value`, `href`, `disabled`, `variant`, `closeOnSelect` |
| `MenuCheckboxItem` | An on and off option. Props: `value`, `checked`, `disabled`, `closeOnSelect`      |
| `MenuRadioGroup`   | A set of radio items. Props: `label`, `name`, `value`                             |
| `MenuRadioItem`    | One choice in a radio group. Props: `value`, `disabled`, `closeOnSelect`          |
| `MenuGroup`        | A labelled section. Prop: `label`                                                 |
| `MenuSeparator`    | A dividing line                                                                   |
