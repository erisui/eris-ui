## Variants

`primary` is the default. Use `accent` for the one action you most want people to take on a screen, such as buying or upgrading. `danger` is for destructive actions.

## Sizes

<Demo id="button-sizes" source={sizesSrc}>

</Demo>

`icon` makes a square button. Give it an `aria-label`, since there is no visible text.

## As a link

Pass `href` and the button renders an `<a>`, so it navigates like a link and screen readers announce it as one.

## Props

| Prop      | Type                                                          | Default                    |
| --------- | ------------------------------------------------------------- | -------------------------- |
| `variant` | `"primary" \| "accent" \| "secondary" \| "ghost" \| "danger"` | `"primary"`                |
| `size`    | `"sm" \| "md" \| "lg" \| "icon"`                              | `"md"`                     |
| `href`    | `string`                                                      | none; renders a `<button>` |

Other attributes, such as `disabled` or `type`, go straight to the element.
