## Focus on close

Closing the dialog returns focus to the trigger. To send it somewhere else, pass a CSS selector as `finalFocus`. Use this when the trigger will not be there afterwards, like a delete button in a row that the dialog removes.

```astro
<h2 id="projects" tabindex="-1">
  Projects
</h2>

<Dialog finalFocus="#projects">
  <DialogTrigger variant="danger">Delete project</DialogTrigger>
  ...
</Dialog>
```

The target must be focusable, so give a heading or container `tabindex="-1"`.

If the trigger is removed, hidden or disabled when the dialog closes and `finalFocus` is not set, focus moves to the nearest focusable ancestor of the dialog, or to the page's `<main>`. It does not fall to `<body>`. This only covers changes made before the dialog closes. If you remove the trigger later, after a request finishes for example, set `finalFocus`.

## Keyboard

| Key                                                 | Does                                                        |
| --------------------------------------------------- | ----------------------------------------------------------- |
| <kbd>Enter</kbd> or <kbd>Space</kbd> on the trigger | Opens the dialog and moves focus inside                     |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> <kbd>Tab</kbd>    | Moves between focusable elements, staying inside the dialog |
| <kbd>Esc</kbd>                                      | Closes the dialog and returns focus to the trigger          |

While the dialog is open, the page behind it does not scroll and screen readers only see the dialog.

## Parts

| Component           | Renders                                                                              |
| ------------------- | ------------------------------------------------------------------------------------ |
| `Dialog`            | The root. Props: `id`, `defaultOpen`, `role`, `closeOnInteractOutside`, `finalFocus` |
| `DialogTrigger`     | The button that opens it. Takes Button's `variant` and `size`                        |
| `DialogContent`     | The backdrop and the dialog panel                                                    |
| `DialogTitle`       | The heading; becomes the dialog's accessible name                                    |
| `DialogDescription` | Supporting text; becomes its accessible description                                  |
| `DialogClose`       | A button that closes it. Takes Button's `variant` and `size`                         |
