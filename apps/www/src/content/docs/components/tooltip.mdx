## Usage

Wrap the element the hint describes and pass the hint as `text`. The tooltip adds no element around it, so your layout stays the same.

The hint attaches to the first focusable element inside: a button, a link, an input, or anything with `tabindex`. To pick a different element, mark it `data-tooltip-trigger`. Put the hint on something focusable, or keyboard users never see it.

While the hint is showing, it is the trigger's description for screen readers. It does not replace the trigger's name, so an icon-only button still needs an `aria-label`.

## Placement

`placement` picks the side of the trigger: `top`, `bottom`, `left` or `right`, each with an optional `-start` or `-end`. The default is `top`. `gutter` is the gap in pixels, 6 by default. The hint flips to the opposite side when it does not fit.

## Delay

The hint opens after the pointer rests for `openDelay` milliseconds, 400 by default, and closes `closeDelay` milliseconds after it leaves, 150 by default. Keyboard focus opens it at once.

</Demo>

## Markup in the hint

For more than plain text, leave `text` out and fill the `content` slot. Keep it short and do not put links or buttons in it: a tooltip cannot be reached with <kbd>Tab</kbd>. Use a [Popover](/docs/components/popover) for that.

<Demo id="tooltip-rich" source={richSrc}>
  <Rich />
</Demo>

Set `interactive` to keep the hint open while the pointer is over it, so its text can be selected.

## On another component's trigger

A tooltip can wrap the trigger of a Dialog or Popover. Both keep working on the same button.

## Keyboard

| Key            | Does                                    |
| -------------- | --------------------------------------- |
| <kbd>Tab</kbd> | Focusing the trigger shows the hint     |
| <kbd>Esc</kbd> | Hides the hint. Focus stays where it is |

Pressing the trigger also hides the hint, and only one hint shows at a time. Inside a Popover or Dialog, <kbd>Esc</kbd> hides the hint and closes the Popover or Dialog in one press.

## Props

| Prop          | Default | Does                                            |
| ------------- | ------- | ----------------------------------------------- |
| `text`        | none    | The hint. Use the `content` slot for markup     |
| `placement`   | `"top"` | Side of the trigger the hint opens on           |
| `gutter`      | `6`     | Gap between trigger and hint, in pixels         |
| `openDelay`   | `400`   | Milliseconds of hover before it opens           |
| `closeDelay`  | `150`   | Milliseconds it stays after the pointer leaves  |
| `interactive` | `false` | Stays open while the pointer is over the hint   |
| `disabled`    | `false` | Never shows the hint                            |
| `class`       | none    | Classes for the hint                            |
| `id`          | random  | Id for the instance, used to build the part ids |
